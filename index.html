About

Security work, built in the open

I am a security researcher and developer based in Iran. My main project is BBT OS, an installable overlay for Kali Linux that packages reconnaissance, web, Active Directory, wireless and smart-card tooling behind a single launcher — so a bounty workflow starts from one desktop instead of a dozen terminals.

Around it I maintain smaller open-source tools: a Python bug-bounty toolkit, a DNS intelligence utility, an Android permission auditor, and SchnellVPN, an Android client built on Xray/VLESS. I care about tooling that is predictable, scope-aware, and honest about what it can and cannot detect.
